# Multilingual Climate Stance Detection Dataset

## Project Overview

This dataset was prepared for the NLP project **"Detecting Stance in Media on Global Warming for Indic Languages."**

The objective is to classify text into three stance categories:

- **Favour:** Supports the concern that climate change and global warming are serious issues.
- **Against:** Rejects, denies or downplays that concern.
- **None:** Does not express a clear stance towards the claim.

## Dataset Statistics

| Language | Training | Validation | Total |
|---|---:|---:|---:|
| English | 1,612 | 403 | 2,015 |
| Hindi | 1,612 | 403 | 2,015 |
| Bengali | 1,612 | 403 | 2,015 |
| **Total** | **4,836** | **1,209** | **6,045** |

## Dataset Sources

The original English dataset combines:
- GWStance
- SemEval-2016 Stance Dataset

Additional datasets were explored, including Dhoroni Bengali and Bengali YouTube News Opinion data, but were not directly incorporated as labelled training data because their labels or content did not consistently match the project's target stance.

## Multilingual Data Generation

Hindi and Bengali examples were generated by translating the original English examples using:

**Model:** `facebook/nllb-200-distilled-600M`

The original English labels were retained for the translated examples.

**Note:** Hindi and Bengali entries are machine-translated augmentations, not independently collected or manually annotated native-language examples. Translation quality and label preservation require further human verification.

## Class Distribution

Original English training data:

| Label | Examples |
|---|---:|
| Favour | 681 |
| Against | 225 |
| None | 706 |

The dataset has class imbalance, particularly in the Against category. Class weighting is considered during model training.

## Data Splitting

An 80:20 stratified split was performed on the original English dataset before translation. All language versions of an original example remain in the same split to prevent cross-language train-validation leakage.

The validation data is synthetic for Hindi and Bengali because it is machine-translated from English.

Faculty-provided test data is kept separate from this repository's training and validation data.

## Intended Use

This dataset is intended for academic research and experimentation in multilingual stance detection.

## Limitations

- Machine translation may change meaning, negation, sarcasm or cultural context.
- Hindi and Bengali labels are inherited from English labels.
- Native-language human annotation is recommended before claiming reliable cross-lingual performance.
- The dataset should not be treated as 6,045 independent original comments.
